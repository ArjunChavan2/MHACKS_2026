# BillLess screen completion plan

Build the existing MVP 2 journey with the established Nunito/Inter typography, navy and pale-blue palette, shared page spacing, rounded cards, and restrained Billy illustrations. Preserve server-authored findings, cited evidence, approval gates, and synthetic-demo labels.

1. **Case tracking:** clear next action, questioned/offered/verified amounts, evidence, paperwork and timeline. Add loading, unavailable and retry states; retain existing information when polling fails.
2. **Document confirmation:** readable document cards, accessible disclosures, comfortable correction controls on phones. Preserve printed values, confirmation requirements and blocking errors.
3. **Letter review:** document-like layout, paragraph evidence, distinct download and case-tracking actions. Keep sending approval on the case screen.
4. **Operator console:** consistent shell, labeled case lookup, readable response cards and visible lookup failures. Keep the console explicitly simulated.

Validate with lint, production build, existing tests and desktop/mobile browser checks. No changes to clinical rules, case transitions or API contracts.
